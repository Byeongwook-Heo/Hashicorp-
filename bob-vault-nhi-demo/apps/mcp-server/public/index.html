신원 확인 우선

안전한 대화는 신원 확인에서 시작됩니다.

IBM Verify가 사용자를 인증하고, 챗봇은 필요한 권한만 요청합니다. 비밀번호와 토큰은 화면이나 에이전트 컨텍스트에 노출되지 않습니다.

  • 사용자 세션은 IBM Verify가 유지합니다.
  • 에이전트는 OBO 토큰으로만 권한을 위임받습니다.
  • 데이터베이스 자격증명은 요청 직후 폐기됩니다.
